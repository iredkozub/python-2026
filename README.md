### Задание 1. Мини-трекер покупок

Программа хранит информацию о покупках и позволяет находить их по идентификатору, а также получать список уникальных товаров;
- list используется для хранения покупок и добавления новых записей;
- tuple представляет отдельную покупку с фиксированной структурой: ID, название товара и цена;
- dict позволяет быстро находить покупки по их идентификаторам;
- set хранит уникальные названия товаров, исключая повторения.
